# `course-2026` becomes the default branch for the semester

For the *Complex Web Services* 2026–27 course, about twenty students fork OcéEns, and a fork starts from the default branch: `course-2026` therefore becomes the repository's default branch. Forks start from it and pull requests target it (including the development login, #82, and the per-role seed, #84). `main` is left untouched during the semester, to give students a stable base and to avoid mixing course-specific code into it; no `main` → `course-2026` synchronisation is planned before the end of the semester.
